# ユースケース

ごほうびスタンプを、だれが、何のために、どう使うかをまとめます。画面やロックの仕様を決めるときの前提にします。

## 利用者

| 利用者 | すること |
| --- | --- |
| 保護者 | 目標とごほうびを決める。頑張りを確かめてスタンプを押させる。ごほうびを渡して記録する |
| 子ども（3〜6歳） | スタンプを押す。目標に近づくのを楽しむ。達成を喜ぶ。過去の頑張りを見返す |

アプリの中心となる体験は「目標を決める → 頑張る → スタンプをためる → 達成を喜ぶ → ごほうびをもらう」です。

子どもが触るのは、見ることとスタンプを押すことだけです。それ以外の変更はすべて保護者が行います。

## 基本の流れ

1. 保護者がシートを作る（がんばること、何回でゴールか、何枚でどのごほうびか）
2. 子どもが頑張るたびに、シートにスタンプを押す
3. ゴールすると、お祝いのあとシートがきろくに残り、同じシートが最初から始まる
4. たまったシートの枚数に応じて、保護者がごほうびを渡し、交換したことを記録する
5. 親子でれきしを見返す

## 画面ごとのユースケース

| 画面 | 利用者 | ユースケース |
| --- | --- | --- |
| シート一覧 | 保護者・子ども | 取り組み中のシートと、それぞれの進み具合を見る。続けるシートを開く |
| シート作成・編集 | 保護者 | がんばること、ゴールの回数、ごほうびを決める・変える |
| シート詳細 | 保護者・子ども | スタンプを押す。ゴールまであと何回か見る |
| スタンプ選び | 子ども | 押したいスタンプを選ぶ |
| ゴールのお祝い | 保護者・子ども | 達成を喜び、もらえるごほうびを見る。同じシートでもう一度始める |
| ごほうび | 保護者 | たまったシートの枚数と、交換できるごほうびを見る。ごほうびを渡したら交換を記録する |
| れきし | 保護者・子ども | 達成したシートを一覧で見返す |
| れきしの詳細 | 保護者・子ども | 完成したシートのスタンプを見返す |
| せってい | 保護者 | 振動、お祝いの演出、おとなロックを設定する |

### シート一覧

- 取り組み中のシートを、ゴールの回数、今の回数、最後に押したスタンプと一緒に見る
- 続けるシートを選んで開く
- ＋から新しいシートを作る
- シートがないときは、作るように案内する

利用シーン：保護者が「はみがきのスタンプを押そう」と声をかけ、子どもとシートを開く。

### シート作成・編集

- がんばること（例：はみがき）を入れる
- 何回でゴールかを − と ＋ で決める（決まった範囲の中で。すでに押した回数より少なくはできない）
- ごほうびを「何枚で何」の形で、いくつでも登録する（例：1枚でおかし、5枚でどうぶつえん）
- 登録したごほうびを直す・消す

利用シーン：子どもと相談しながら「10回できたらシート1枚、シート5枚でどうぶつえん」と約束を決める。

### シート詳細

- 押したスタンプと日付を、すごろくのような盤面で見る
- 「スタンプを押す」から、スタンプを選んで押す。押すとスタンプを押しつける演出と振動がある。続けて何度押しても1回だけ数える
- ゴールまであと何回かを見る
- 押したスタンプを長押しして、別のスタンプにかえる・とりけす（押し間違えの修正）
- メニューから、シートを編集・削除する
  - シートを削除しても、それまでのきろくはれきしに残る

利用シーン：はみがきを終えた子どもが自分でスタンプを選んで押し、「あと2回だね」と話す。押したあと、シートを見て「何のスタンプを押したかな」と確かめることもある。

### ゴールのお祝い

- ゴールのスタンプが押される演出と紙吹雪で、達成を喜ぶ
  - ゴールのスタンプは毎回ランダムに選ばれる
  - 画面をタップすると演出を飛ばせる
- 今もらえるごほうびと、次のごほうびを見る
- 「わかった」で同じシートを最初から始める
- 「ごほうびを編集」で、内容を変えてから始める

利用シーン：10回のはみがきを達成し、親子で一緒に喜ぶ。

### ごほうび

- シートごとに、たまったシートの枚数と、交換できるごほうびを見る
- 次のごほうびまで、あと何回・何枚かを見る
- ごほうびを渡したら「交換する」で記録する。交換できるごほうびが1つなら確認だけ、複数あればどれと交換するか選ぶ。使ったシートの枚数だけ、たまったシートが減る

利用シーン：週末に、まだ渡していないごほうびがあるか確かめ、お菓子を渡したあと交換を記録する。

### れきし・れきしの詳細

- 達成したシートを、ゴールのスタンプ、達成日、回数と一緒に見返す
- ごほうびと交換済みかどうかを見る
- 完成したシートを開いて、押したスタンプと日付を見返す（「はみがきを 10かい がんばりました！」）
- いらないきろくを削除する

利用シーン：「前にもこんなに頑張ったね」と、親子で過去のシートを見返す。何と交換したかを細かく管理するより、頑張りを振り返ることを大事にする。

### せってい

- 振動、ゴールのお祝いアニメーションのオン・オフを切り替える
- おとなロックを設定する
- バージョン、プライバシーポリシー、お問い合わせ、ストアのページを開く
- 使っているライブラリやフォントのライセンスを見る

## おとなロック

子どもが保護者の操作を勝手にしないように、操作の前にかんたんな計算問題を出します。初めはオフです。

| 操作 | 利用者 | おとなロックがオンのとき |
| --- | --- | --- |
| 画面を見る、タブを移動する | 保護者・子ども | ロックしない |
| ゴールのお祝いで「わかった」 | 保護者・子ども | ロックしない |
| 振動、お祝いアニメーションの切り替え | 保護者 | ロックしない（子どもが触っても困らない） |
| ライセンス、プライバシーポリシーなどを開く | 保護者 | ロックしない |
| スタンプを押す | 保護者・子ども | 「スタンプを押すときもロックする」がオンならロックする（初めはオン） |
| シートを作る・編集する・削除する（「ごほうびを編集」を含む） | 保護者 | ロックする |
| スタンプをかえる・とりけす | 保護者 | ロックする |
| ごほうびを交換する | 保護者 | ロックする |
| きろくを削除する | 保護者 | ロックする |
| おとなロックの設定を変える | 保護者 | ロックする |

スタンプを押すことだけを選べるのは、子どもが自分で押してよい家庭と、大人が確かめてから押させたい家庭があるためです。

解除が続く期間：

- スタンプを押す：解除してから、スタンプを押すまで続く。スタンプ選びを閉じてシートを見直し、もう一度ボタンを押しても聞き直さない。シートの画面を離れると、またロックする
- おとなロックの設定：解除してから、設定画面を離れるまで続く
- それ以外：操作のたびに聞く

## まだない機能

検討して、まだ作っていない機能です。

| 機能 | 利用者 | ユースケース | 状況 |
| --- | --- | --- | --- |
| バックアップと復元 | 保護者 | 機種変更しても、シートときろくを引き継ぐ | 予定。ファイルへの書き出しと読み込み |
| 効果音 | 保護者・子ども | スタンプを押したときやゴールしたときに音で楽しむ。音を消すこともできる | 予定。設定画面に「効果音」のスイッチを足す |
| さいしょのスタンプ | 子ども | スタンプ選びで、いつも使うスタンプを最初に選んでおく | 見送り |
